# 2Devs Game Studio

Official landing page for **2Devs Game Studio**, an independent game development company founded by **Omar AbdElzaher Sleam** ([omar92.github.io](https://omar92.github.io/)) and **Mohamed Hamdy** ([m-hamdy23.github.io](https://m-hamdy23.github.io/)).

## Pages
- **Studio Home (`index.html`)** — Company overview, engineering DNA, studio games catalog, founder profiles, and contact information.
- **Gaming Lounge Simulator (`games/gaming-lounge-simulator.html`)** — Dedicated game showcase covering gameplay pillars, shop terminal tabs, genre sign marquee, parody game catalog, and full-size media previews.

## Structure
```text
2devsgamestudio.github.io/
├── index.html                           # Studio home page
├── games/
│   └── gaming-lounge-simulator.html     # Dedicated game page
├── css/
│   └── styles.css                       # Shared responsive stylesheet
├── js/
│   └── main.js                          # Tabs, genre filter, marquee control, and lightbox dialog
└── assets/
    ├── screenshots/                     # Gaming Lounge Simulator UI & storefront previews
    ├── covers/                          # Sample parody game box-art sheets
    └── signs/                           # 12 genre category badges
```
