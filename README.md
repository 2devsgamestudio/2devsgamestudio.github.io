# 2Devs Game Studio

Official landing page for **2Devs Game Studio**, an independent game development studio founded by **Omar AbdElzaher Sleam** ([omar92.github.io](https://omar92.github.io/)) and **Mohamed Hamdy** ([m-hamdy23.github.io](https://m-hamdy23.github.io/)).

## Featured Project
- **Gaming Lounge Simulator** — A stylized first-person video-game retail store and arcade lounge simulation built in Unity, featuring 600+ parody boxed titles across 12 genres, a 3-layer dynamic demand and 28-day season calendar simulation, store customization, staff management, and a 75-node radial skill tree.
